# rahulbailur.github.io

My portfolio, served by GitHub Pages at https://rahulbailur.github.io.

A static site with no build step: `index.html`, `style.css`, `app.js` and `assets/`.

- Liquid glass panels over a WebGL caustic background. Chromium browsers get real refraction
  (SVG displacement maps through `backdrop-filter`); other browsers get the frosted version.
- A draggable glass lens in the hero, a liquid navigation dock, and light and dark themes.
- CareFlow section with a latency chart and a failover model, and a section on the Muthoot
  gold-loan voice assistant. Each live demo has a status light that pings its free server so it is awake by the
  time someone clicks through.
- Command palette: press Ctrl K (⌘K on Mac) or `/` to jump to any project, skill or link.
- Respects the reduced motion and reduced transparency system settings.
